## 📖 Описание проекта

**Smile AI** — это современное мобильное приложение для iOS и Android, разработанное на Flutter, которое предоставляет интеллектуального бизнес-ассистента на основе искусственного интеллекта. Приложение предназначено для предпринимателей, бизнесменов и специалистов, которые нуждаются в быстрых и качественных консультациях по различным бизнес-вопросам.

### Ключевые особенности проекта:

- **🤖 Умный AI-ассистент** — интеллектуальный чат-бот, способный отвечать на вопросы по маркетингу, аналитике, стратегии развития бизнеса и другим темам
- **📊 Бизнес-аналитика** — отслеживание трендов, популярности направлений и получение AI-рекомендаций на основе данных
- **📝 Готовые шаблоны** — библиотека шаблонов для различных бизнес-задач с возможностью создания персональных шаблонов
- **💬 Многоуровневая поддержка** — интеллектуальная система поддержки с автоматическим переключением между AI-ассистентом и живыми операторами
- **🌐 Мультиязычность** — поддержка русского и английского языков с возможностью переключения в настройках
- **🎨 Адаптивный дизайн** — поддержка светлой и темной темы с автоматическим переключением
- **📱 Кроссплатформенность** — единый код для iOS и Android с нативным пользовательским опытом

Приложение является частью экосистемы Smile AI и интегрируется с backend API на Rust и Telegram ботом для расширенной функциональности.

## 📱 О приложении

**Smile AI** — это мобильное приложение для iOS и Android, которое предоставляет бизнес-ассистента на основе искусственного интеллекта. Приложение помогает предпринимателям и бизнесменам получать консультации по маркетингу, аналитике, стратегии развития и другим бизнес-вопросам.

### Основные возможности:

- 🤖 **AI-чат** — общение с умным ассистентом для получения бизнес-консультаций
  - 🎙️ **Голосовой ввод** — преобразование речи в текст с поддержкой русского и английского языков
  - ⚙️ **Настройки контекста** — настройка контекста беседы (роль пользователя, этап бизнеса, цели, срочность, регион, ниша) для получения более релевантных ответов
  - 💬 **История чатов** — сохранение и управление историей бесед с возможностью переименования и удаления
  - 📄 **Обработка файлов** — получение, просмотр и возможность поделиться Excel и CSV файлами, сгенерированными AI
  - ✍️ **Markdown форматирование** — поддержка форматирования текста (жирный, курсив, заголовки, таблицы, списки) с применением в реальном времени
- 📊 **Аналитика** — отслеживание трендов и популярности различных бизнес-направлений
  - 📈 **Визуализация данных** — интерактивные графики и диаграммы
  - 🎯 **AI-аналитика** — умные рекомендации на основе данных
- 📝 **Шаблоны** — готовые шаблоны для различных бизнес-задач
  - 📁 **Персональные шаблоны** — создание и управление собственными шаблонами
  - 📂 **Папки шаблонов** — организация шаблонов в папки
  - 🎨 **Адаптивные цвета** — поддержка темной и светлой темы для всех шаблонов
- 👤 **Профиль** — управление личными данными и настройками
  - 📸 **Аватар профиля** — загрузка и отображение фотографии профиля
  - 📱 **Telegram синхронизация** — привязка Telegram аккаунта для синхронизации чатов с Telegram ботом
  - 🔒 **Проверка надежности пароля** — валидация пароля при регистрации с предупреждением о слабых паролях
- 💬 **Поддержка через Telegram** — интеллектуальная система поддержки с двумя режимами работы
  - 🤖 **AI-режим** — автоматические ответы от AI-ассистента (режим по умолчанию)
  - 👤 **Human-режим** — переключение на живых операторов через Telegram группу
  - 🔄 **Автоматическое переключение** — система автоматически переключается на операторов при запросе пользователя или недоступности AI
  - 📨 **Синхронизация сообщений** — отправленные пользователем сообщения и ответы поддержки отображаются в реальном времени через WebSocket
  - 🔔 **Системные уведомления** — информационное сообщение о переключении на оператора показывается только один раз
- 🌐 **Локализация** — поддержка русского и английского языков
- 🌓 **Темная тема** — адаптивный дизайн с поддержкой светлой и темной темы
- 📱 **Уведомления** — push-уведомления о новых сообщениях от AI с отображением аватарки приложения

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd smile_ai
```

### 2. Установка зависимостей

```bash
flutter pub get
```

### 3. Настройка .env файла

Файл `.env` создается автоматически при первом запуске приложения с пустыми значениями. Если нужно настроить вручную, создайте файл `.env` в корне проекта:

```env
AUTH_TOKEN=
USER_ID=
USER_EMAIL=
USER_FULL_NAME=
USER_NICKNAME=
USER_PHONE=
USER_COUNTRY=
USER_GENDER=
USER_TELEGRAM_USERNAME=
CONTEXT_USER_ROLE=
CONTEXT_BUSINESS_STAGE=
CONTEXT_GOAL=
CONTEXT_URGENCY=
CONTEXT_REGION=
CONTEXT_BUSINESS_NICHE=
```

### 4. Генерация локализации

```bash
flutter gen-l10n
```

### 5. Настройка нативного splash screen

```bash
dart run flutter_native_splash:create
```

### 6. Запуск приложения

#### Для iOS:

```bash
# Запуск на симуляторе
flutter run -d ios

# Или откройте проект в Xcode
open ios/Runner.xcworkspace
```

**Важно для iOS:**
- Убедитесь, что в `ios/Runner/Info.plist` добавлены разрешения для доступа к галерее:
  ```xml
  <key>NSPhotoLibraryUsageDescription</key>
  <string>Приложению необходим доступ к галерее для выбора аватара</string>
  <key>NSCameraUsageDescription</key>
  <string>Приложению необходим доступ к камере для выбора аватара</string>
  ```

#### Для Android:

```bash
# Запуск на эмуляторе или устройстве
flutter run -d android
```

**Важно для Android:**
- Убедитесь, что в `android/app/build.gradle.kts` включена поддержка core library desugaring (уже настроено)

### 7. Сборка релизной версии

#### Для iOS:

```bash
flutter build ios --release
```

Затем откройте `ios/Runner.xcworkspace` в Xcode и создайте архив для App Store.

#### Для Android:

```bash
flutter build apk --release
# или для App Bundle
flutter build appbundle --release
```

## 📱 Использование приложения

### Первый запуск:

1. При первом запуске приложение автоматически создаст `.env` файл с пустыми значениями
2. Выполнится проверка здоровья сервера (`/health`)
3. Если токен отсутствует или невалиден, откроется экран входа

### Регистрация:

1. Нажмите "Зарегистрироваться"
2. Введите email
3. Введите код подтверждения (по умолчанию: `1111`)
4. Создайте пароль (минимум 8 символов)
5. Заполните данные профиля
6. После успешной регистрации откроется главный экран

### Вход:

1. Введите email
2. Введите пароль
3. После успешного входа откроется главный экран

### Основные функции:

- **AI-чат**: Откройте главный экран и начните общение с AI-ассистентом
- **Аналитика**: Перейдите на вкладку "Аналитика" для просмотра трендов
- **Шаблоны**: Используйте готовые шаблоны для быстрого создания запросов
- **Профиль**: Настройте приложение, измените язык, тему и данные профиля

## 🔐 API Endpoints

Приложение использует следующие API endpoints:

### Аутентификация и профиль:
- `GET /health` — проверка здоровья сервера
- `GET /api/auth/check-token?token=` — проверка валидности токена
- `GET /api/auth/check-user?email=` — проверка существования пользователя (возвращает `profile_picture`)
- `POST /api/auth/login` — вход в систему
- `POST /api/auth/register` — регистрация (с поддержкой `telegram_username`)
- `PUT /api/auth/profile?token=` — обновление профиля (с поддержкой `telegram_username`)
- `GET /api/auth/profile/{user_id}` — получение данных профиля (включая `profile_picture` и `telegram_username`)
- `POST /api/auth/profile-picture?token=` — загрузка фотографии профиля

### Чат и контекст:
- `POST /api/chat/message` — отправка сообщения в чат (с поддержкой `context_filters`)
- `GET /api/chat/history/{conversation_id}` — получение истории чата
- `GET /api/chat/conversations/{user_id}` — получение списка бесед (с полем `context`)
- `POST /api/chat/conversations` — создание беседы с контекстом
- `PUT /api/chat/conversations/{conversation_id}/context` — обновление контекста беседы

### Аналитика:
- `GET /api/analytics/top-trend` — получение топ-тренда
- `GET /api/analytics/popularity` — получение трендов популярности
- `GET /api/analytics/weekly-trends` — получение недельных трендов
- `GET /api/analytics/ai-analytics` — получение AI-аналитики
- `GET /api/analytics/niches-month` — получение ниш за месяц

### Файлы:
- `GET /api/files/{file_id}` — получение файла по ID
